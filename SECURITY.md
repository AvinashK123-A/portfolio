# Security policy

This repository is the source of a static personal portfolio site
(<https://portfolio-xi-three-4uo4n9ctro.vercel.app>). Only the current `main` branch and
the production deployment built from it are maintained.

## Reporting a vulnerability

Please email **avinash.kommareddybe@gmail.com** with:

- what you found and where (URL, file or dependency),
- steps to reproduce or a proof of concept,
- the impact you expect.

Please do not open a public GitHub issue for a vulnerability, and do not test against the live
site in ways that could degrade it for others (load testing, automated scanning at volume).

## Scope

In scope: the site's code and configuration in this repository, including response headers and
dependencies. Out of scope: Vercel's and GitHub's own infrastructure (report those to them), and
findings that need a compromised browser or device.
